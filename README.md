# CPU Monitor

A lightweight terminal-based CPU monitoring dashboard built with Python.

## Features

- Live per-core CPU utilization
- CPU frequency monitoring
- CPU temperature
- RAM usage
- CPU topology
- Socket and physical core mapping
- Logical CPU visualization
- Live terminal dashboard
